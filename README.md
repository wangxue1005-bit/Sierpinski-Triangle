# AP1 交互式2D分形 谢尔宾斯基垫片

## 运行方式
直接打开index.html，浏览器支持WebGL2即可。

## 实现要点
1. **两种生成算法**
- 混沌游戏：随机选取三角形顶点，当前点与顶点取中点迭代生成点云；点数随动画逐步增长。
- 递归细分 `subdivide()`：递归切分三角形，设置递归深度控制细节。

2. 三种渲染模式
- POINTS(按键1)：混沌游戏点云渲染
- LINES(按键2)：递归细分线框
- TRIANGLES(按键3)：递归细分实体填充

3. 参数面板
- 递归深度0‑6；点大小；3套配色；混沌最大点数
4. 交互
- 鼠标左键拖拽平移；鼠标滚轮缩放
- 键盘`1/2/3`切换渲染模式；空格暂停/继续点生长动画

## 遇到的坑
1. gl_PointSize 只在POINTS图元生效；
2. 混沌动画持续生成顶点，使用DYNAMIC_DRAW；
3. 鼠标坐标需要映射到NDC标准化设备坐标，做缩放系数修正；
4. 递归深度过大时顶点数量爆炸，限制最大深度为6。
