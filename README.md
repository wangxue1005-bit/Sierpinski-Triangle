# AP1 交互式2D分形 谢尔宾斯基垫片
## 运行方式
访问公网可运行URL，浏览器支持WebGL2即可直接运行。
本地运行：下载源码，双击index.html用浏览器打开。

## 实现要点
1. 两种生成算法
- 混沌游戏：随机选取三角形顶点，取当前点与顶点中点迭代生成点阵；点数随动画逐步增长。
- 递归细分 `subdivide()`：递归切分三角形，设置递归深度控制细节。
2. 三种渲染模式
- TRIANGLES：实心填充递归三角形
- LINES：线框轮廓模式
- POINTS：混沌游戏动态点阵生长

## 交互说明
- 键盘1：切换混沌点阵模式，自动生长
- 键盘2：切换线框递归模式
- 键盘3：切换实心填充递归模式
- 空格：暂停/继续点阵动画
- 鼠标拖拽画布：平移图形
- 鼠标滚轮：放大缩小图形
- 页面滑块：调整递归深度、点大小、生成点数
